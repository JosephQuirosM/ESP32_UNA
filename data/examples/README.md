# Muestras de captura

Esta carpeta no distribuye un dataset de calibración ni una muestra sintética. Los CSV reales se generan con el receptor y los artefactos experimentales se excluyen de Git; pueden existir en otras carpetas de la copia local.

Cualquier muestra compartida debe conservar el esquema CSV v3 de `python/receptor_gateway.py` y documentar procedencia, geometría, tabla MAC→ubicación, sesiones y limpieza aplicada. Consulte [el protocolo de campo](../../docs/prueba_campo_captura.md) y [la arquitectura actual](../../docs/arquitectura.md).
