# Muestras de captura

La primera muestra CSV v3 debe provenir de una prueba física aprobada, anonimizada si fuera necesario y conservar el esquema definido en `python/receptor_gateway.py`. No se incluye una muestra sintética para evitar confundirla con datos de calibración reales. La captura histórica v2 permanece en `data/raw`, pero no debe copiarse aquí como ejemplo del contrato vigente.
